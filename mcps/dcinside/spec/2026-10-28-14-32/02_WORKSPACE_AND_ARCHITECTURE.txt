TECH
- TypeScript strict mode, Node.js 22 LTS; follow existing repo Node version if stricter.
- pnpm workspace (do not nest a second workspace if one exists).
- Official @modelcontextprotocol/sdk, zod, vitest; versions must be checked against installed workspace and current SDK APIs when implementing.
- ESM exports or existing repository module strategy.
- stdio transport as default. No HTTP server in P0.
- No browser automation package; no cheerio/http scraping library in P0.
- Use native fetch ONLY for Brave's official search endpoint. No arbitrary URL fetch.
- Keep tool handlers thin: validation -> service -> structured result/error.

SDK
Use the current officially supported MCP server registration and StdioServerTransport APIs compatible with the installed SDK. Expose explicit input schemas and descriptions. Return concise text JSON and, where supported, machine-readable structuredContent. For tool failures use isError=true and stable error codes without secrets.
