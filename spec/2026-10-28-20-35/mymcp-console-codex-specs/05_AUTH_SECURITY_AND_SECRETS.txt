PHASE 05 — SINGLE OWNER AUTHENTICATION, LOCAL SECURITY HARDENING
Priority: P0, must be done BEFORE exposing any invocation endpoint

[1] Threat model
- 공격면: 콘솔 웹 UI, 백엔드 HTTP API, local stdio child process, process env, logs/history,
  사용자가 붙여넣는 tool argument, DCInside 검색 결과/가져온 내용, Docker/macOS 경로.
- MCP Console은 도구 실행 권한을 부여하므로 개인정보/명령 실행/비밀키 노출을 특히 주의.
- '개인용'은 인증 생략 이유가 아님. OS loopback 외 인터페이스는 기본 금지.

[2] 인증
- 단일 소유자 계정, 별도 사용자 가입/초대 API 없음.
- `CONSOLE_ADMIN_PASSWORD_HASH` (Argon2id PHC encoded hash) 환경변수로 초기 비밀번호 검증.
- 비밀번호 평문을 env에 장기 저장하는 대안 금지. 설정 CLI 스크립트 `pnpm console:hash-password` 제공,
  해당 CLI는 stdout에 hash만 출력, 입력 password를 history/로그/프로세스 인수에 남기지 말 것.
- admin hash 미설정이면 API는 fail-closed, 화면에는 안전한 setup 안내만 표시.
- 성공 로그인 시 crypto-secure 랜덤 session token 생성, 서버측 token hash 저장(SQLite).
- 세션 cookie HttpOnly, SameSite=Strict, Path=/, Secure(HTTPS 환경), 적절한 만료 (예: 12h).
- cookie raw token 외부 로그/DB에 기록 금지. 서버 저장 hash만 사용.
- 로그인 rate limit: 계정/소스 기준 5회/15분, 429, 성공/실패 audit event.
- 로그아웃/세션 만료/관리자 hash 변경 시 기존 세션 무효화.
- production에서 HTTP 접근을 외부 네트워크에 공개하지 않음. HTTPS behind trusted reverse proxy 필요.

[3] CSRF / Origin / session
- 변경 요청(POST/PATCH/DELETE)에 Origin 검증 + 세션 기반 CSRF token(`X-CSRF-Token`) 확인.
- 로그인 POST도 허용 origin만 받고 Login CSRF 위험 방지.
- session endpoint는 no-store, cookie 내용을 JSON으로 반환하지 않음.
- 외부 iframe/embedded 페이지를 통한 도구 호출 방지: CSP frame-ancestors 'none'.
- Content-Security-Policy: default-src 'self', script-src 'self', object-src 'none', base-uri 'none',
  connect-src same-origin. Monaco worker 구동 정책은 Vite 번들 기준으로 조정하되 unsafe-eval 기본 금지.
- X-Content-Type-Options nosniff, Referrer-Policy strict-origin-when-cross-origin or no-referrer.

[4] Command execution boundary
- 브라우저에서 command/args/cwd/env 및 URL을 임의 전달하는 endpoint 절대 없음.
- registry 항목은 코드/설정 배포 시 관리자가 검토한 경로만 허용.
- `exec`/`execSync`/`shell:true` 금지. StdioClientTransport에 고정 command+args만 전달.
- `path.resolve`, `realpath`로 runtimeRoot 경로 외부 escape, symlink path, traversal 차단.
- unverified/disabled MCP 연결 거부. GET status는 허용.
- Docker socket, SSH key, host root, host filesystem 전체 bind mount 금지.
- 모든 write Tool은 어노테이션이 readOnly인지와 별도로 서버 정책으로 분류하고 명시적 사용자 확인.
- `dc_import_post`는 데이터 수정 Tool이다. `destructiveHint:false`이므로 괜찮다고 자동 실행하지 말 것.

[5] Secret handling
- 브라우저에는 env VALUE 절대 전달하지 말고 configured/missing 여부만 전달.
- Brave API key 등은 컨테이너 환경변수/secret manager로 전달. `.env.console.example`은 placeholder only.
- 정적 JSON registry에 secret literal 금지, env 키 이름만 allowlist로 허용.
- MCP child에 불필요한 모든 부모 env를 상속시키지 말고 필요한 키만 whitelist로 전달.
- NODE_ENV, PATH 등 필수 런타임 변수도 고정 allowlist로 관리.
- logs/analytics DB에 request arguments 및 raw content 기본 저장 금지.
- secret 마스킹 기준: Authorization/Bearer, API key, password, cookie, token, private path,
  그리고 json field names `*_KEY`, `*_TOKEN`, `password`, `secret` (필요 시 확장).

[6] Rate/limits and untrusted content
- global HTTP rate limits and tool calls limits. `/api/auth/login` separate stricter limit.
- DCInside search는 Brave API 비용/쿼터 대상. 자동 반복 검색 금지, UI에서 사용자 직접 호출만 허용.
- `dc_search_posts` 검색 결과는 오래되거나 불완전할 수 있으니 source `search_index`/coverage note 표시.
- `dc_get_post`는 import되지 않은 본문을 실시간 수집하지 않음. `NOT_IMPORTED`를 UI에 설명.
- HTML, Markdown, code, links in Tool outputs untrusted; display as escaped text / sanitized JSON.
- 임의 외부 URL 자동 열기/자동 fetch/HTML 실행하지 않음.

[7] Test Cases
[ ] 해시 없는 상태 로그인 불가.
[ ] session 재사용/만료/로그아웃 동작.
[ ] CSRF 없이 Tool call 실패, wrong Origin 실패.
[ ] unverified server request returns 409 without spawn.
[ ] malicious registry path/args/symlink rejected.
[ ] response/log/history에 BRAVE_SEARCH_API_KEY 값 포함되지 않음.
[ ] UI source bundle과 API responses에 server env secret 없음.
[ ] write Tool은 confirmWrite false/미설정 시 403.
[ ] 크로스사이트 XSS payload가 iframe/script로 실행되지 않음.
